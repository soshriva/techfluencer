# Sourabh Shrivastav - Platform Fieldnotes

My personal technical publication featuring Learning Loops and weekly Field
Notes about Kubernetes, private cloud, AI, automation, and architecture.

The site uses two primary content formats:

- **Learning Loops:** structured tutorials with comparisons, knowledge checks,
  and applied architecture questions.
- **Field Notes:** weekly standalone articles, explainers, and observations.

## Run locally

Open `index.html` directly in a browser, or serve the directory with any static
HTTP server.

## First Learning Loop

Publish one complete lesson titled **What Is VKS?**, containing:

1. A vendor-neutral Kubernetes concept introduction.
2. The VKS implementation and responsibility model.
3. A comparison with upstream, OpenShift, EKS, AKS, or GKE.
4. One architecture diagram.
5. A five-question knowledge check with answer explanations.
6. A realistic architecture decision challenge.
7. Version and validation dates.

## Before publishing

- Review employer policy, trademarks, screenshots, and disclosure requirements.
- Validate every product-specific claim against current official documentation.
- Add a privacy notice before collecting email addresses or analytics.
